<!-- ABOUT PROJECT -->

## 📌 About The Project

<p>

The <b>Vehicle Rental System</b> is a <b>console-based Java application</b> built using <b>Object-Oriented Programming (OOP)</b> concepts.

This project allows users to:

</p>

<ul>

<li>Register as Customer</li>

<li>View Available Vehicles</li>

<li>Rent Vehicle</li>

<li>Return Vehicle</li>

<li>View Booking Details</li>

</ul>

<p>

This project is mainly created for <b>placement preparation</b> and demonstrates real-world application design.

</p>
